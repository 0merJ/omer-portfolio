# Portfolio assets

Place local files in `public/assets/`.

## Images

| Path | Purpose | Recommended format |
| --- | --- | --- |
| `images/omer-portrait.jpg` | Hero and personal portrait | JPG/WebP, landscape or portrait, at least 1200px on the long edge |
| `images/drone-hero-web.jpg` | Flagship drone project hero | JPG/WebP, 4:3 or 16:10 |
| `images/drone-yolo-detection.jpg` | YOLOv8 detection output | PNG, 16:9 |
| `images/drone_dashboard.png` | Tkinter monitoring dashboard | PNG, 16:9 |
| `images/drone-simulation.jpg` | SITL simulation | PNG/JPG, 16:9 |
| `images/mobile-robot-map.jpg` | Generated mobile robot map | JPG/PNG |
| `images/mobile-robot-simulation.JPG` | Robot simulation screenshot | JPG/PNG, 16:9 |
| `images/leo-rover-hero.jpg` | Leo Rover project image | JPG/WebP |

## Videos and diagrams

The drone demonstration is available at `videos/drone_demo.mov`. Controls are provided and the video does not autoplay.

## Documents

Add your CV at `documents/Omer_Javed_CV.pdf`; the hero, navigation and contact links already point to `/assets/documents/Omer_Javed_CV.pdf`.

Only add media you own or have permission to use. Update captions and alt text in `src/data.ts` when replacing media.
